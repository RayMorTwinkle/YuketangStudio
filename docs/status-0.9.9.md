# 0.9.9 状态记录

日期：2026-10-30

## 本轮修复

### AI 题图体积

- `agnesChat` 发请求前统一扫描 `messages` 中的图片。
- 大于 500KB 的 data URL 压到 500KB 以内；请求体在测试样本中从约 4.7MB 原图降到 591KB。
- 压缩只作用于请求副本，不改变界面里的原图。
- 远程 http(s) 图片会先尝试转 dataURL 再压缩。

### 旧版作业

- 「在脚本内查看」现在显示每道题的题图预览、题型和分值。
- 没有题图时显示「无图」，不再是一条不可辨认的列表行。
- 题图加载使用直连 + `fetchAsDataURL` 兜底；一张题图都没加载成功时明确报错，不再生成白图。
- 批量 AI 从作业列表移到当前题目页，只处理当前作业的多道题。
- 批量答案通过 `cache_each_result` 暂存，不交卷；提交交给用户。

### 移动端

- 刷课面板改为内部滚动，压缩头部按钮，禁用时隐藏暂停/停止。
- PPT 对话上下文无图时显示「（无图）」，不再挤压长原因文案。
- PPT 对话与 AI 解答共用上下文/输入区样式。

## 验证

- 单元测试：164 通过，0 失败
- Answer Engine E2E：22 通过，0 失败
- 图片压缩 E2E：4.7MB → 443KB，请求体 591KB，通过
- 旧版题图预览合成测试：3 题渲染出 2 个预览 + 1 个「无图」
- Android 0.9.9 release 构建通过
- 真机移动端截图：刷课头部/按钮完整可见，PPT 上下文显示「（无图）」

- 批量暂存的真实接口往返（代码复用现有 cache 路径）
