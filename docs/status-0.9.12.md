# 0.9.12 正式版状态记录

日期：2026-11-01

## 发布内容

- 云端文本模型升级；公开状态与设置页只显示「模型1 / 模型2」，不暴露上游来源。
- 服务端公开状态接口隐藏上游名称、原始错误、baseUrl 和 model；真实名称仅管理页可见。
- 服务端文本健康/视觉健康分开监测，支持空响应、SSE 错误、视觉 4xx 检测。
- 脚本设置仅在云端模型时显示上游状态；AI 解答/PPT 对话异常时提示但允许继续尝试。
- 工具栏自动答题开启前检查云端状态，异常时劝阻并推荐自有 API Key。
