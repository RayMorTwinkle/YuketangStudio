# 0.9.13 正式版状态记录

日期：2026-11-02

## 发布内容

### 课件页

- 修复课件容器超出面板下界：改为 header 固定、body flex、列表/导航轨共享剩余高度，不再用 `height:100%` 叠满整个面板。
- 修复顶部按钮被课程名长度挤到换行/遮挡：课件选择器可收缩，桌面端 header 保持单行，移动端按钮完整可见。

### 考试

- 课程学习日志中的 type=5 试卷/考试现在会进入「作业/考试」列表。
- 当前考试页不再预先写死「已交卷」；读取官方 cover 后才显示真实状态。
- `result.status=1` 显示进行中/未交卷，不再显示「暂无法获取考试状态」。
- type=5 考试增加「打开考试」入口（长江雨课堂考试域）。
- 当前考试页可识别为考试上下文，「AI 填入」按钮不再因路由识别失败而隐藏。

### 刷课
