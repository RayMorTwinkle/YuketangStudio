# 0.9.10 状态记录

日期：2026-10-31

## 修复

### 设置开关加固

- 手机端开关从左侧移到右侧，避开部分系统悬浮窗/边缘手势的点击区域。
- 开关点击停止事件冒泡，防止触发宿主页面或 shell 其他处理。
- 切换后恢复设置面板 `scrollTop`，避免焦点滚动造成“白屏”观感。
- 设置面板 `overscroll-behavior: contain`，不把滚动传给宿主页面。
- 仍保留设置同步/保存失败时的局部 try/catch，不让异常清空面板。

### 账号重复提示

根因方向：旧指纹在没有 `user_profile` 时会退到 token，token 轮换后同账号被判为新账号。

- 优先使用 `user_profile.user_id` 作为稳定身份。
- 兼容旧版本裸 token 指纹和 `token:` 前缀指纹。
- 同名旧 profile 自动选最新一份并更新，不再为同一账号堆重复 profile。
- 手动保存账号遇到已有身份时改为更新。
- 同一稳定身份/同名账号只自动提示一次；之后可在账号管理里手动保存。
- 增加对话框去重，避免页面连续加载叠多个弹窗。
