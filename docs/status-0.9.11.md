# 0.9.11 状态记录

日期：2026-11-01

## 服务端

- 新增 `GET /yuketangstudio/status?code=...`，只返回供应商健康摘要，不返回 key/baseUrl/model。
- 文本健康与视觉健康分开记录：
  - 文本 4xx/5xx/timeout/429
  - 视觉 4xx、200 空响应、SSE 错误/空正文
- 非流式响应会校验 JSON choices/content；流式响应会解析 SSE 并检测 error/空正文。
- 主动探活改为 30s 超时，并校验返回正文；视觉能力增加小图探测。
- 管理页增加「视觉 / 视觉错误」列。
- 当前上游实测：
  - `ark`：文本可用；plan 接口的 `deepseek-v4-flash` 不是视觉模型；已将 `vision=false`。
  - `agnes`：文本健康；视觉请求返回 400/429，视觉状态标记异常。
  - 当前云端视觉能力不可用；文本能力可用。
